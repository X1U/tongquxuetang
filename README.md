# 童趣学堂 Android 应用

“童趣学堂”提供图卡游戏、数量学习、听觉与复述练习、听觉训练卡、唐诗阅读和七巧板乐园。网页、图卡、生活音效、诗词资料和七巧板关卡都打包在 `app/src/main/assets/index.html` 中，安装后可离线学习；中文指令与句子可使用手机系统声音或首页选择的联网发音人。联网发音人和首页版本检查需要网络。原项目目录、应用包名、签名和学习记录沿用。

后续安装包只在项目内生成：构建产物为 `app/build/outputs/apk/debug/app-debug.apk`，发布归档位于 `.releases/pgyer/`，不再额外复制到桌面根目录。

GitHub 私有仓库的上传范围及新电脑恢复步骤见 [GitHub 使用说明](GitHub使用说明.md)。

## IDEA 中启动手机 IP 预览

1. 用 IDEA 打开本目录，在底部 Terminal 中运行 `node .\手机预览.cjs`。本机已安装所需依赖；换电脑后先运行 `npm ci --prefix tools/online-speech`。
2. 保持终端运行，将手机与电脑连接到同一局域网；电脑使用网线时，手机连接该路由器的 Wi-Fi。
3. 在手机浏览器输入终端打印的 `http://电脑IP:8765/` 地址。电脑自己可访问 `http://127.0.0.1:8765/`。
4. 首页点右上角“听听声音”试播，再进入游戏。手机的媒体音量需要打开。
5. 保存 `app/src/main/assets/index.html` 后，刷新手机浏览器即可看到修改。修改 `手机预览.cjs` 或 `server/` 后，需要先按 Ctrl+C 停止，再重新运行预览。

服务监听所有本机网卡，提供游戏页面和中文音频。手机通过 IP 打开时，电脑按所选发音人使用 Windows 本机语音或在线朗读服务生成音频，手机用普通音频播放器播放；不要求手机浏览器支持系统朗读，不需要麦克风权限或商业云语音密钥。想离线朗读时，需要电脑已安装可用的 Windows 中文声音。

更新预览服务后需要重启一次，再刷新手机页面。页面首次请求读取并压缩一次，之后复用内存内容；每次请求仍检查文件是否更新。中文音频保留独立缓存与分段请求支持，首次朗读新内容需要由电脑生成音频。

若旧预览已在后台运行，可以在 IDEA 的 PowerShell 终端执行 `.\启动语音预览.ps1`，重启本项目的后台预览并检查语音是否就绪。它只会停止经页面核验属于本项目的旧预览；如果端口被其他程序占用，会提示而不会关闭其他程序。后台日志位于 `.checks/voice-compat/preview-stdout.log` 和 `preview-stderr.log`。

若修改的是独立网页版源文件，先运行 `同步网页.ps1` 再刷新预览。页面生成器会同步两个网页；修改预览后端后运行 `node scripts/sync-preview.cjs`，把服务和固定版本依赖同步到独立网页版目录。电脑 IP 变化后，以启动时打印的地址为准。使用期间保持电脑开机、预览服务运行，手机和电脑连接同一局域网。

## 自动发布到蒲公英

已经接入固定版本的蒲公英官方 CLI，默认**公开安装**。已配置 `PGYER_API_KEY` 时可直接使用；也可以在 IDEA 终端运行 `.\发布蒲公英.ps1 -Login` 完成账号授权。每次同时递增 `app/build.gradle` 的 `versionName` 和 `versionCode`，更新 `发布说明.txt`，再运行 `.\发布蒲公英.ps1`，即可完成构建、APK 校验、上传、等待发布及输出安装链接。

账号密码使用 `PGY_USERNAME`、`PGY_PASSWORD` 环境变量；上传认证仍需 `PGYER_API_KEY` 或官方 CLI 一次网页授权。发布入口会读取已配置的当前进程、Windows 用户或系统变量，凭据不写入项目、不输出日志。本机工具已安装；首次配置、更多命令和 CI 接入说明见 [蒲公英自动发布](蒲公英自动发布.md)。

首页底部提供当前版本、更新说明、检查更新和安装入口。具体行为、系统变量和后续发布注意事项见 [版本更新说明](版本更新说明.md)。
