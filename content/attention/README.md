# 专注力听觉训练卡

本题库为童趣学堂原创，使用生活情景和简单的动物故事。每张卡先给出一句话，再围绕原句提出多个问题。

例如：“小兔在花园里给红花浇水。”随后依次问“谁在浇水？”“小兔在哪里浇水？”“小兔给什么浇水？”。

## 内容

`cards.json` 保存 24 张卡、96 个问题：起步、进阶、挑战各 8 张，每张分别有 3、4、5 个问题。起步关注人物、地点和事情；进阶增加时间、颜色和数量；挑战增加多个人物、细节和先后顺序。

每张卡的 `sentence` 为一句完整的话。每个问题有三个互不重复的 `options`、一个唯一的 `answer`，以及来自原句的 `evidence`。所有答案都能从本句中直接找到，不依赖图片、常识猜测或前一张卡。

## 使用

从首页进入“专注力听觉训练卡”，或在网页地址末尾加 `#attention`。先听完整句，再点“开始答题”。题目逐个出现，点“听题”可听问题和三个选项；也可以重听原句。每问只记录第一次选择，显示正确答案后才能继续。

答完一张卡后显示原句、每问答案及本次正确数；可“再练这张”或换下一张。每档采用不重复轮换，遍历完后重新排列。答题不计时。

原句在听题和答题阶段默认收起，需要时可打开“原句提示 / 家长读题”。完整播放失败或中断不会解锁第一次答题；家长可以手动读完整句，再点“家长读完了”。只关闭提示不算读完。本次使用过文字帮助会在结果页提示。

声音与语速沿用首页设置，使用已有的 `ListeningAudio` 和长期音频缓存。进入卡片和切换问题时提前准备相关朗读；换卡、换难度、换活动、切换语音设置及进入后台会取消旧播放。内容、选项和记录功能均内置，联网发音人的新内容仍需要网络；可使用本机声音或家长读题。

- 内容源：`content/attention/cards.json`。
- 界面与流程：`modules/attention/`；构建接入：`scripts/build-attention.cjs`。
- 修改后运行 `node scripts/build-poetry.cjs`，生成安卓内嵌页面并同步独立网页版。APK 需要重新构建。
- 构建检查三档数量、单句格式、问题数、选项唯一性，以及答案和依据都来自原句。
- 新记录使用 `tongqu-attention-v1`，保存难度、每张卡最好正确数和完成次数；不修改原游戏记录。无法使用浏览器存储时仍能完成当次练习。
- 安卓系统返回先关闭本活动的提示，再回首页；路由接入 `MainActivity` 的返回处理。
