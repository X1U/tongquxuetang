# 唐诗内容与校对

1.13 以百度汉语为原文及注音对照参考，保留原选本全部 320 个条目和 ts-001 至 ts-320 稳定编号。《长信怨五首》等仍合为一篇，目录顺序、分类和旧版阅读记录不变。正文不含异文说明；长诗完整保留。

## 来源与覆盖

原文底本为 chinese-poetry/chinese-poetry 的 `蒙学/tangshisanbaishou.json`。原始文件、MIT 许可和下载摘要保存在 `source/`，未覆盖修改。页面“关于”仍可查看完整许可。

百度汉语公共页面已取得 320 篇对应原文；按汉字比较、不计标点空格，当前有 246 篇相同，74 篇仍有参考差异。`baidu-review.json` 保存 4 处本次原文字词校订、48 组按诗句限定的读音修正，以及相应注释。其他写法在“异文”中并列，不将参考页面截缺的正文带入。

取得 188 篇完整参考注音，另外 132 篇未取得完整参考注音，不能称为全部逐字核验。字形规范、轻声、一/不变调及古今异读可能造成差异；明确的多音字错误结合词义校正，不机械接受参考页的自动注音。系统朗读由操作系统决定，可能与页面注音不同。

`百度汉语校对记录.md` 提供全部篇目对应链接与覆盖状态；`baidu-audit.json` 保存紧凑的原文差异、读音差异和摘要。实际抓取的公共 HTML 与原始记录仅保存在 `.checks/baidu-source/`，不打包进应用。不使用登录凭据或私有接口。

## 学习内容

每篇提供译文、注释、背景、简析、赏析。讲解为童趣学堂自编的学习辅助内容，并非百度汉语等网站现代译注的逐段转载，也不冒充官方教材。未确定的背景或有争议的解释会明确说明。

- `studies/*.jsonl`：每行 `[序号, [译文段落...], 背景, 赏析]`。320 条记录、607 段译文。长诗按叙事和诗意分段，避免只解释开头。
- `annotations/*.jsonl`：旧格式 `[序号, 旧场景, 简明诗意, [[词语, 释义], ...], 旧图注]`。简明诗意用于“简析”，词语注释经审订后共 1024 条。旧场景和图注只保留为源记录，不再读取或打包。
- `pronunciations.json`：姓名、地名与常用多音字覆盖表，其余由锁定版本的 pinyin-pro 生成。`baidu-review.json` 中的本篇读音规则最后应用，避免修改同字在别篇的读法。词语注音优先复用本诗正文读音。
- `corrections.json`：早期题名补全和正文修正，包括补全《赠卫八处士》后十六句；与本次校订一起应用。

详情页已去掉诗意图。首页封面使用 `modules/poetry/cover.js`；旧 `illustrations.js` 不再嵌入生成页面。原文和五栏目均离线可读，参考外链和检查更新需要网络。

## 生成与核验

1. 缺少生成依赖时运行 `npm ci --prefix tools/poetry-data --ignore-scripts --no-audit --no-fund`。
2. 修改原文或注音规则后运行 `node scripts/prepare-poetry-data.cjs`，生成 `poems.base.json` 和 `catalog.tsv`。
3. 已有本地抓取记录时，运行 `node scripts/build-poetry-reference.cjs` 更新校对摘要。校对记录已入项目，普通界面或讲解修改不需要联网重抓。
4. 运行 `node scripts/build-poetry.cjs`：校验 320 篇、五栏目、逐字注音与摘要，生成 `poems.json`，同步安卓内嵌网页和独立网页版。
5. 验证后运行 `构建APK.ps1`。APK 只在项目目录内生成；1.13/14 已于 2026-09-16 17:34 按用户确认发布为蒲公英 Build 8。后续发布仍使用项目发布入口。

`scripts/audit-baidu-poetry.cjs` 只在需要更新参考记录时使用，读取百度汉语公开 HTML，保留缓存和断点。访问限流或验证页会停止，不绕过访问限制。可用 `--only 8,17` 指定篇目；`--refresh` 重新解析记录，已缓存页面仍复用。不要将原始网站文章放进发布资源。

`modules/poetry/` 为界面维护源，HTML 中 `poetry:*` 标记以内的内容由生成器维护。目录自适应分页，正文和讲解在固定阅读框内滑动，底部只换上一篇/下一篇。五栏各自记忆阅读位置并支持朗读、键盘切换；兼容旧版阅读记录。

`.checks/tongqu-preview.cjs` 验证 320 篇、1600 个讲解栏目、七种屏幕尺寸、全文与注音完整性、分类/搜索和阅读位置。`.checks/baidu-poetry-data.cjs` 验证原文变化范围和典型多音字；语音、缓存、更新功能分别由 `.checks/poetry-audio-regression.cjs`、`.checks/poetry-preview-regression.cjs`、`.checks/update-regression.cjs` 检查。

目前可以完整使用全部五栏目。若要把剩余 132 篇也标为对照注音已核验，需要可访问的百度汉语逐字注音页，或指定可采用的可靠注音版本；范围见校对记录中“未取得”的篇目。若要求网站现代译注原文直接转载，需另提供可使用的内容及授权。
