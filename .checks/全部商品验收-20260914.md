# 图卡学习乐园 1.2：全部商品显示与图标放大

日期：2026-09-14。

## 本次要求与实现

以之前的九件商品页面 `before-large-cards.html` 为参照，恢复全部商品同时展示，并扩大商品图标。

- 商品区始终使用三行三列展示本轮全部九件商品，任意一件都可直接选择。
- 移除三张商品的补位状态和隐藏规则；归位后在原商品位置显示完成标记，不移走其图卡。
- 恢复货架内的图片及名称：用途为三个竖向货架，材质为三个横向货架。
- 缩减重复说明、面板边距和按钮间空白，为商品图片分配更多高度；手机商品名称为 12–14px。
- 保留已完成的密码返回状态、刷新图标、图文答案、分类理由朗读和找不同类玩法。
- 已同步独立网页版。手机 IP 预览直接读取安卓页面，刷新即可看到修改。

## 放大幅度

对比同一视口中的上一版九件布局和本版，九件商品均同时显示。以下为商品 SVG 显示区域高度，单位为 CSS 像素；图片使用相同的绘图坐标范围。

| 手机视口 | 上一版 | 本版 | 高度增幅 |
| --- | ---: | ---: | ---: |
| 320 × 568 | 18.2 | 29.8 | 约 64% |
| 360 × 640 | 31.1 | 43.4 | 约 40% |
| 412 × 840 | 58.0 | 77.0 | 约 33% |

测量数据位于 `nine-goods-size-comparison.json`，测量脚本为 `layout-size.cjs`。
