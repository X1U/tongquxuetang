## 已实现行为

选择联网声音后，进入题目、诗词和讲解时提前准备当前内容；长诗首段最多 80 字，后续最多 220 字，播放时准备后两段。准备与点击朗读共享同一合成任务，点击优先处理；最多两个合成同时进行，后台准备最多占一个。

安卓长期音频位于应用私有的 `no_backup/voices/v1/`，电脑预览位于各自项目的 `.voice-cache/online-v1/`。按文字、发音人及语速区分，最多约 64 MiB、1000 条，自动清理较久未用的音频；长度和摘要校验失败的缓存重新生成。重开应用、重启手机和普通覆盖升级可保留安卓缓存；清除应用数据或卸载会删除。不新增存储权限。

换题、换活动、改声音或语速、进入后台会取消过时的准备和播放，旧回调不再启动下一段。修复了朗读中切换“听令行动 / 九字传话”时，旧取消回调访问新题型数据而中断页面的问题。新增缓存代码已改用 Android 6.0 / API 23 支持的接口。

已有发音人、五档语速、学习记录、真实生活录音和 App 内更新功能保留。未缓存且尚未提前准备的内容仍需要联网等待；缓存会按容量淘汰，不能保证所有内容永久离线。
