# 1.7 手机浏览器语音兼容验收

用户环境：安卓手机浏览器，通过电脑 IP 访问。用户已在本次对话中刷新 `http://10.48.201.6:8765/` 并点击首页“听听声音”，反馈“能听到声音”。未记录手机型号或具体浏览器名称，不把本次结果扩展为所有安卓浏览器的真机验证。

## 完成内容

- 电脑使用 Windows 中文声音 `Microsoft Huihui Desktop` 生成普通 WAV 音频，手机通过同源音频接口播放，不依赖手机浏览器的系统朗读功能。
- 五个游戏接入同一播放器，覆盖题目、提示、分类解释、数量点数及数字书写讲解。密码与分类保留慢速。
- 首页增加“听听声音”和播放状态。换题、切换游戏、停止朗读、隐藏页面会取消旧音频；连续点击会重新播放，避免音频重叠。
- 播放失败提示重试，失败后可以恢复播放；隐藏页面后不会遗留首页播放状态。
- 预览服务继续监听 `0.0.0.0:8765`，仅提供游戏页面、中文语音状态及音频。音频支持 HEAD 和字节范围请求，内容校验、并发合并、队列限制和缓存容量限制均已实现。
- 独立网页版、安卓内嵌页面及两份预览服务文件已经同步，IDEA 启动说明及独立版使用说明已更新。

## 验证结果

`voice-compat-regression.cjs` 已通过：真实中文 PCM WAV，22,050 Hz / 16 bit / 单声道，音频数据非静音；慢速、缓存、并发合成、HEAD、Range、非法参数及文件访问范围检查正常。

浏览器测试明确移除 `speechSynthesis` 和 `SpeechSynthesisUtterance`，不提供 `AndroidTts`，通过实际触摸点击播放。18 个播放场景记录了真实 `playing` 事件、音频时长和前进的播放位置，涵盖首页与五个游戏；完成、停止、切换、错误提示和恢复也通过验证。手机首页在 320×568、360×640、412×840、760×900 下完整显示五个入口和试播按钮，并已查看 360×640 截图。

最终页面的原有回归检查全部通过：数量与书写 195 项、数量随机/顺序模式 148 项、找规律 214 项、找影子 224 项、密码与全部九件商品分类 235 项。独立版数据验证覆盖 12 段脚本解析及五个游戏题库。

发布核对脚本：`verify-voice-release.cjs`。报告位于 `voice-compat/report.json` 和 `voice-compat/apk-verification.json`。实际音频样本为 `voice-compat/verified-chinese.wav`。
